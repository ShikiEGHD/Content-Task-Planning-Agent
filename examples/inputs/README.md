# 输入格式草案

minimal-request.draft.json 仅用于讨论字段，当前没有可运行 CLI 或已实现的输入 schema。

- task_id：用于重复执行与幂等的任务标识；具体规则待选。
- topic：内容主题。
- budget：业务模拟单位；本例为 10。
- deadline：带时区的截止时间。示例是固定测试日期，不可直接当作每次运行的未来时间。

正式实现需另行提供正常、缺预算、缺截止时间、资料不足、工具失败、可降本、无可行方案、重复执行及达到上限等输入。故障注入使用独立测试配置，不冒充生产业务参数。

评估会使用固定时钟或与运行时间匹配的输入，防止样例因日期推移意外过期。
