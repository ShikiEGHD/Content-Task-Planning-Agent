# 输入格式

`minimal-request.draft.json` 仅用于展示字段；正式场景文件可直接交给 CLI。

- task_id：用于重复执行与幂等的任务标识，允许字母、数字、下划线和连字符。
- topic：内容主题。
- budget：业务模拟单位；本例为 10。
- deadline：带时区的截止时间。示例是固定测试日期，不可直接当作每次运行的未来时间。

仓库已提供正常、缺预算、缺截止时间、素材不足、工具失败、截止时间不可达、预算 9.00/8.99 边界、输入变更场景；上限通过 CLI 参数控制，幂等使用相同 runtime 重复执行。

评估会使用固定时钟或与运行时间匹配的输入，防止样例因日期推移意外过期。
