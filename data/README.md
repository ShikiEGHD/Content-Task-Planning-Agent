# 合成素材和规则

assets.json 是合成素材目录，不代表真实活动效果；脚本需保留素材使用限制，不编造实测数据。
tool_catalog.json 定义整数模拟分、成功/失败工具费、成功/失败模拟分钟、制作费和工期、审核/发布费及分钟。
100 分 = 1 模拟单位；API 真实费用与该预算分开。

v2 使用 review_cents/publish_cents 计算费用，review_minutes/publish_minutes 计算时间，不能混用。
报价包含累计实际工具费和剩余必需工具费；历史候选制作报价不作为实际支出重复累计。
检索 → 生成、估算 → 保存有依赖；只对独立脚本调用和独立制作任务并行排程，失败和重规划耗时保留。
