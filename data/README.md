# 合成数据

后续在此放置合成素材与工具费用、耗时规则，不使用私人素材、客户资料或真实凭据。

待实现的数据：

- assets.json：素材 ID、主题标签、可用内容、限制条件、可替代素材。
- tool_catalog.json：工具/内容形式的费用、预计耗时、失败调用是否收费等规则。
- scenario_fixtures.json（可选）：可重复的不足、故障与超预算情景。

所有金额均使用模拟单位，推荐用整数最小单位计算。业务模拟成本与真实云端模型 token 费用分开记录。实际计费规则需用户确认；不得将方案估价与实际发生费用重复相加。

时间规则需包含明确时区、固定测试时钟和串行执行假设；不以真实等待来模拟数小时的业务工作。
