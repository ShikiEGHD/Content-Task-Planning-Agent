# 02 方案设计与技术取舍

## 结构和已确认选型

Python 3.12.2、LangGraph 1.2.10、argparse、dataclass/手动校验、unittest。
DeepSeek 通过 OpenAI Python SDK 3.42.0 直连原生工具调用，默认 `deepseek-flash`，关闭思考模式。Mock 采用相同接口，固定规则只验证流程。
备选框架、路由、存储、生成方式与优缺点的比较记录保留在 [路线](00-roadmap.md)，选型均来自用户确认。

LangGraph 使用 `StateGraph`、节点、条件路由、START/END，负责图循环和状态传递；业务工具、费用时间、失败收费、幂等、保存守卫、Trace 由项目实现。
没有使用 LangChain 模型包装器和 checkpointer；LangGraph 的传递依赖不等于使用其模型包装器。

## 决策循环

输入校验 → decide 模型节点 → execute 受控工具节点 → 更新真实状态/Trace → decide → finish。
模型收到素材摘要、脚本 ID、估算、最近工具返回、错误、累计费用和耗时、完整费用表及限制，选择动作和一句可核验依据。
程序验证字段、call_id、批次是否合法并控制工具上限；不会替云端模型选择降本方案。

图状态含 request/config、版本、run_id、素材、所有成功草案、当前选定脚本估算、已保存结果、实际费用、模拟耗时、错误、工具事件。
历史成功草案会保留，但 estimate_cost 的 `script_ids` 才是最终执行集合。选多个就合计多个制作费，不能隐式只算最后一个。
生成新草案使估算失效；保存前检查选定脚本、素材和费用表的依赖指纹。方案保存后冻结业务动作，只允许结束，避免保存内容与最终输出分离。

## 费用（accounting_version=2）

所有金额为整数模拟分，100 分 = 1 个模拟单位。真实供应商 API 账单独立，不称为美元或人民币。

报价总额 = 已发生工具费用 + 本次估算成功费 + 待保存成功费 + 选定脚本制作费之和 + 审核费 + 发布费。

成功和失败按费用表分别收费；报价金额不是实际支出，重规划时不累加旧制作报价，但实际生成、检索、估算和失败费用都保留。
保存前按当前费用重新计算，只预留本次保存费，已计入的估算费不重复收取；保存成功后将保存费计入实际费用，pending 清零。
保存文件、最终输出、幂等索引的选定方案估算和实际费用一致。

正常 Mock：工具费 225 + 图文制作 575 + 审核 50 + 发布 50 = 900 分。
预算 900 分恰好允许保存；899 分必须返回不足 1 分，不能仅依赖旧 feasible 布尔值。

## 工期与并发

费用表 minutes/failure_minutes 为业务模拟耗时；真实工具调用通过线程池执行并记录墙钟秒，不用 sleep 模拟业务时间。
检索必须先于依赖素材的脚本，批次之间串行累计；同批多个独立脚本按请求顺序分配到最多 `min(--concurrency, max_workers)` 个执行槽，批次工期取槽负载最大值。
失败、额外检索、重新生成、重复估算都增加模拟工期。候选生成虽不最终采用，其已发生时间也不能删除。

预计总工期 = 已发生规划分钟 + 待估算/保存分钟 + 选定脚本制作任务并行排程分钟 + 审核分钟 + 发布分钟。
审核/发布依赖全部选定制作完成，不能与制作假设并行。固定测试时钟使用带时区 `--now`，预计完成时间不得超过 deadline；不足 1 分钟的超期向上取整。
正常 Mock：2 + 8 + 1 + 8 + 1 + 1 + 30 + 15 + 10 = 76 分钟。

## 本地持久化与幂等

JSON 原子替换，runtime 进程锁阻止同目录跨进程竞争；独立生成线程不写索引，状态更新串行。
幂等指纹覆盖输入、计算版本、config、素材、费用表和故障配置。相同有效输入复用已有记录；输入或规则变化自动创建版本，v1 缓存不会伪装成 v2 结果。
测试时间不作为输入版本的一部分；已完成结果代表历史已保存任务。CLI 不支持跨进程失败步骤续跑，相同失败记录也会复用，需独立 runtime 才重新执行。

## 输出和记录

`--output` 直接原子写 UTF-8 JSON，成功和输入/配置错误都写出结果。stdout/stderr 显式 UTF-8；无需 PowerShell `>`，避免 GBK/UTF-16 重编码。
`reason_code` 区分模型结束、步数上限、调用上限和输入/配置错误；CLI 成功退出 0，未完成退出 2。
Trace 使用 UTF-8 JSONL，记录 mode、run_id、task_id、步骤、模型动作/工具参数、返回摘要、状态、简短 reason、单次及累计费用、累计模拟耗时。
不记录 API Key、认证头或模型内部推理。最终输出含计算版本、模型名、Trace 路径及实际墙钟执行秒。

v2 两条真实云端路径和离线结果详见 [评估](03-evaluation.md)。正常路径修正非法估算批次后完成；持续故障路径由工具调用上限终止，未实现模型主动放弃重复失败。
